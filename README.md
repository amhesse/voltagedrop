# voltagedrop
A voltage drop calculator for a string of single-phase AC loads.

**Use it online: https://amhesse.github.io/voltagedrop/** (or open `index.html` locally).

Enter the source voltage, power factor, drop target and each
segment's length and load; the page picks the lowest-cost conductor sizes that meet both the
drop target and NEC ampacity, or you can fix a size per segment.
